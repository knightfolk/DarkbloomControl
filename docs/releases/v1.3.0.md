# Darkbloom Control v1.3.0

- Activity charts separate models with related colors by company. Click a model
  pill to filter the chart and results; choose bars, lines, or area, and stacked
  or side-by-side bars.
- New chart markings and signed profit axes improve readability.
- Estimated profit per earning model-hour subtracts an equal share of whole-Mac
  electricity cost from each model with recorded work in a fully covered hour.
  The estimate includes other Mac activity; hours with power gaps are omitted.
- Overview adds measured Mac-wide CPU utilization, provider-reported active and
  cached GPU memory, and available GPU temperature/fan readings.
- GPU engine utilization is not reported by the provider and is not inferred.

## Compatibility

Apple Silicon, macOS 14 or newer. Install the official Darkbloom CLI separately;
it is not bundled or modified.
