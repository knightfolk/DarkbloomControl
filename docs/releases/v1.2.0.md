# Darkbloom Control v1.2.0

- Activity charts color each model separately and keep base rewards distinct.
- Clearer time and USD axes make hourly and daily charts easier to read.
- Per-model average recorded work earnings are shown per earning-hour, with the number of recorded hours. These are gross earnings: they do not subtract electricity or count hours without model earnings.
- The menu-bar model list follows the provider's saved model selection, and its model rows show current or stale network demand when available.

## Compatibility

Apple Silicon, macOS 14 or newer. Install the official Darkbloom CLI separately; it is not bundled or modified.

## Verification

557 Swift tests across 73 suites and 13 packaging tests passed. Distribution signing, notarization, appcast publication, and the installed-app upgrade smoke test are pending release credentials and the final release artifact.
