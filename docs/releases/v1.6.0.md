# Darkbloom Control v1.6.0

- Add Chat inside the dashboard and in a separate resizable window. Both views
  share one in-memory conversation; prompts and replies are discarded on quit.
- Make the destination explicit for each new conversation. Local hosting is the
  default. If the local endpoint is unavailable, sending stays disabled until
  you choose another destination; chat never switches to the paid network on
  its own.
- Add an opt-in Darkbloom network route with a clear paid-inference warning,
  consumer balance and pricing information, and a fresh balance check before
  each send. The network can still reject a request when credits are
  insufficient. The consumer API key is stored in the macOS Keychain.
- Add local hosting controls for loopback or LAN access, model selection, and
  optional endpoint bearer authentication. Chat also supports a local endpoint
  intentionally configured without a bearer token.
- Keep beta review builds separate from the installed app's preferences,
  history, and single-instance lock so they can run side by side.
