# Darkbloom Control v1.5.0

- Show best-effort, whole-Mac GPU utilization in the provider resources panel,
  alongside the provider's reported GPU memory.
- Show provider request activity: `1+` while inference is active and the exact
  accepted requests remaining during a graceful drain.
- Use the CLI's native graceful-stop behavior to pause new admissions and drain
  accepted work, replacing the app's former idle-polling stop flow.
- Keep the Models window within the visible screen area with a compact toolbar
  and responsive, enabled-first model cards.
